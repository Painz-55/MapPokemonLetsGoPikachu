# Atlas de Kanto — Pokémon Let's Go, Pikachu!

Mapa interativo e responsivo de apoio para a jornada em Kanto. Permite buscar locais, Pokémon e itens, destacar áreas lendárias, navegar pelos andares internos e abrir mapas das dez principais cidades. Cada cidade lista edifícios visitáveis, casas, NPCs importantes, recompensas, trocas por formas de Alola e encontros aquáticos por Sea Skim.

## Executar localmente

```bash
npm install
npm run dev
```

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a branch `main`.
2. Em **Settings → Pages → Build and deployment**, escolha **GitHub Actions**.
3. O fluxo **Publicar no GitHub Pages** fará a publicação automaticamente.

O caminho base é calculado durante a publicação, portanto o site funciona tanto em repositórios de projeto quanto em repositórios `usuario.github.io`.

## Fontes e aviso

Os dados foram organizados a partir dos guias de [Bulbapedia](https://bulbapedia.bulbagarden.net/wiki/Appendix:Let%27s_Go,_Pikachu!_and_Let%27s_Go,_Eevee!_walkthrough) e [Serebii Pokéarth](https://www.serebii.net/pokearth/kanto/). As vistas das cidades pertencem ao jogo e foram obtidas no arquivo da Bulbapedia; os marcadores e mapas de apoio são uma camada editorial criada para este guia.

Pokémon Let’s Go não possui vara de pesca. Por isso, o guia trata os Pokémon solicitados como encontros aquáticos por **Sea Skim**, informando quando a água pertence a uma rota adjacente.

Este é um projeto de fã, independente e não oficial. Pokémon e nomes relacionados pertencem à Nintendo, Game Freak, Creatures e The Pokémon Company.
